# 🦖 C++ Pokémon Battle Simulator

A lightweight C++ console application that preloads a classic Generation 1 Pokémon database, tracks player win metrics on a grand leaderboard, and simulates turn-based combat based on speed mechanics.

## 🚀 How to Run the Game

### Option 1: Quick Run in the Browser (Easiest)
1. Open the `main.cpp` file in this repository and copy all the code.
2. Go to [OnlineGDB's C++ Compiler](https://onlinegdb.com).
3. Clear the default text, paste the code, and click **Run**.

### Option 2: Local Compilation (For Visual Studio)
1. Download this repository as a `.zip` file and extract it.
2. Open Visual Studio and create a new **C++ Empty Project**.
3. Right-click **Source Files** > **Add Existing Item**, and select `main.cpp`.
4. Press `Ctrl + F5` to compile and launch the game!
